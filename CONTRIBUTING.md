# Contributing to Chester Agsamosam's Portfolio

Thank you for your interest in contributing to this portfolio project!

## Development Guidelines

1. **Code Standards**:
   - Written in Vue 3 (Composition API) and Nuxt 4 with TypeScript.
   - Styling handled via Tailwind CSS v4 and vanilla CSS tokens in `app/assets/css/main.css`.
   - Maintain full SEO metadata, Schema.org JSON-LD compliance, and accessibility standards.

2. **Branching**:
   - Create a topic branch: `git checkout -b feature/your-feature-name`
   - Make atomic, clean commits with descriptive commit messages.

3. **Submitting Changes**:
   - Ensure `pnpm build` succeeds with zero errors.
   - Open a pull request against the `main` branch with a summary of the improvements.
